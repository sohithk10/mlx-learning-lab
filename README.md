# MLX Spatial Learning Lab

An interactive 3D browser simulation of MLX arrays, lazy graphs, evaluation,
and CPU/GPU streams. Includes guided quizzes and Markdown learning-log export.

Website: https://sohithk10.github.io/mlx-learning-lab/

GitHub Pages publishes the root of the main branch. No build step or custom
Actions workflow is required. Edit index.html, style.css, and app.js, then push
to main to update the site.

For local preview, run `python3 -m http.server 8765` in this directory.

This is a browser simulation, not an MLX runtime. Progress lasts for the current
tab; export the learning log to keep it. Written explanations are not AI-graded.
